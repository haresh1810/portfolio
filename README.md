# Haresh Makwana Portfolio

A responsive personal portfolio website for Haresh Makwana, showcasing professional skills, education, services, selected work, and contact details.

## Description

This portfolio presents Haresh Makwana as a full-stack developer and system administrator with experience in web development, web application development, content writing, SEO, and web security. The site is designed to provide a clear overview of his technical expertise and make it easy for visitors to get in touch.

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Fixed navigation with mobile menu support
- Home, About, Skills, Education, Services, Works, and Contact sections
- Technical skills displayed with progress bars
- Responsive services grid
- Project and portfolio work gallery
- Direct email link in the Contact section
- Contact form that opens a prefilled email draft
- Smooth scrolling and active navigation states

## Run Locally

No build tools or dependencies are required.

1. Clone or download the project.
2. Open `Index.html` in a web browser.

For a local development server, run the following from the project directory:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Contact Form

The contact form uses a `mailto:` link to open a prefilled message in the visitor's default email application. The visitor must click Send in that email application for the message to be delivered.
